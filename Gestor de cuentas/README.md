# Gestor de Cuentas

Proyecto simple en Python para registrar usuarios en un archivo JSON.

## ¿Qué hace?

- Agrega usuarios nuevos
- Verifica si ya existen
- Guarda los datos en `usuarios.json`
- Sigue funcionando entre ejecuciones

## Requisitos

- Python 3.8+

## Cómo usarlo

```bash
python "Gestor Cuentas.py"
```

Luego elegís:
- `1` para agregar un usuario
- `0` para salir

## Archivos

- `Gestor Cuentas.py` — lógica principal
- `usuarios.json` — almacenamiento de usuarios
- `README.md` — documentación

Proyecto educativo para practicar manejo de archivos y programación en Python
