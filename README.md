# Prácticas y Proyectos de Análisis de Datos

Repositorio destinado a centralizar ejercicios, mini proyectos y prácticas de laboratorio desarrollados de forma autodidacta, académica y en el marco de cursos de especialización. El objetivo principal es afianzar conceptos técnicos, consolidar la lógica de programación y construir una base sólida de código aplicable al análisis de datos.

## Stack Tecnológico Principal

* **Lenguaje:** Python 3
* **Manipulación y Análisis de Datos:** Pandas, NumPy
* **Bases de datos:** SQL, MySQL
* **Visualización:** Matplotlib, Seaborn, Power BI
